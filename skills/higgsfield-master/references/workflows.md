# Ten end-to-end recipes (researched 2026-10-13)
Each recipe: chain, proof step, QA, compliance. Always preview-first, preflight cost, no publishing without user yes. Chain symbol: ->.

## 1. Product ad, one-click (fastest)
Marketing Studio template (Product Showcase, TV Spot or Hyper Motion) from product photo or URL -> Brand Kit -> 9:16 -> generate 3 variations -> Virality Predictor as a rough filter -> overlay text in editor. QA: label legible, one product. Compliance: claims.

## 2. Product ad, controlled (premium)
Packshot (front, clean) -> Nano Banana Pro hero still (exactly one product, angle locked) -> Seedance 2.0 i2v with product as reference, one camera move, 720p proof -> final 1080p -> Seedream de-slop only if people present -> Topaz or FLUX upscale selected take -> add type overlay and audio bed. Angle-lock: camera moves, product never rotates to unseen sides.

## 3. UGC ad (creator style, synthetic creator disclosed or real consented creator)
Soul 2.0 creator portrait (anti-slop module) or consented Soul ID -> Seedream de-slop -> script with sensory lines, no banned phrases (H: no "obsessed", "game changer", greeting openers) -> Seedance 2.0 or Kling 3.0 clips 9:16 with native speech, hard cuts between beats -> frozen-frame QA (hands, label) -> concat. Or Marketing Studio UGC preset with avatar. Label AI persona.

## 4. Brand film (60-90s)
Brief and art-direction bible -> Soul Location and Soul Cinema look-dev -> locations as Elements -> characters as Elements -> shot list (hook, desire, obstacle, discovery, signature image) -> Cinema Studio 4.0 scenes up to 30s with Director's Panel -> Extend for continuity -> grade hero frame and match -> Eleven or native audio -> upscale. Prove hardest shot first.

## 5. AI influencer series
AI Influencer builder (or Soul Cast) -> generate 20+ portraits across angles and lights -> train Soul ID -> save Element -> weekly content: Soul 2.0 stills + Genjutsu Motion Transfer from real reference footage + Lipsync Studio voice -> consistent captions, disclosed as virtual. Keep persona bible and disclosure log.

## 6. Music video
Concept, lyrics or track, beat map -> Popcorn storyboard (8 frames) -> Soul Cinema frames -> Kling 3.0 multi-shot or Seedance 2.0 with @audio for sync -> mute native audio and score independently where needed (V tip) -> Speed ramps (Impact, Bullet Time) on drops -> edit to beat. Style pack: 10-music-video.

## 7. Ad variant factory (scale a winner)
Take best Meta ad -> Ad Multiplier: swap product, cast, location, hook, CTA (one variable each) -> 480p proofs -> 1080p finals -> Reframe for 4:5 and 1:1 -> log hit rates. Static: Ads Studio 20 ads per product at 4 credits each to test angles first.

## 8. Static campaign images
Brand Kit from URL -> Ads Studio (20 per run) for offers; Nano Banana Pro or Marketing Studio Image for hero scenes; Recraft for vector marks; Expand and Reframe for sizes (IG 4:5, Story 9:16, FB 1:1, banner 16:9 or 21:9); overlay type outside the model.

## 9. Faceless explainer or short
Supercomputer Faceless Video or Shorts Maker: give topic, audience, hook line, style (12 visual styles), length -> approve script -> approve plan and credit estimate -> generate -> subtitles -> review facts. Use for educational ingredient or ritual content that avoids medical claims.

## 10. Talking avatar and multilingual
Consented spokesperson Soul ID image -> script -> Lipsync Studio (Veo 3.1, Kling Avatars 2.0, Speak 2.0) or native-audio Seedance -> Audio tool Translate (18 languages) or Eleven v4 for dubbing -> Sync Lipsync 3 for video-to-video re-lip-sync -> subtitles. Voice clone only with written consent.

## Chaining patterns (legend)
- Image -> animate -> upscale -> lipsync: still on Soul Cinema or Nano Banana, motion on Seedance or Kling, upscale selected take, lipsync last.
- Popcorn frames -> Kling start frames -> last frame becomes next clip.
- Real phone footage -> Genjutsu Motion Transfer or Restyle -> polished ad without filming new talent.
- Draft Seedance Fast -> final Seedance 2.0 same prompt; Draft Kling Turbo -> final Kling 3.0.
- Veo 3.1 hero insert inside a Seedance or Kling edit for the single shot that needs best realism.
- Mixed models in Canvas for repeatable pipelines (credits deducted, no Unlimited).
- Hero-frame grade first, then match every keyframe.
- Keep a ledger and kill underperforming shot types after about 30 attempts (3P).

## 11. Academy ad pipeline (official course, 2026-10-13)
Assets (product sheet, grey-background character sheet with one face, 3/4 locations, prop sheets) -> test each location with the hero, one variable at a time -> Claude prompt-builder skill writes the shot list with one shared style header -> generate scene by scene in Seedance 2.0 -> name each failure, fix the shot list, change one variable -> layout map for spatial locks -> cut best takes, keep a take ledger. Details: academy-lessons.md.

## 12. Higgsfield 3-step realism ad (creator blog 2026-10-07; details: photoreal-humans ai-prompting-realism.md section 10)
Chain: asset projects (character sheet 3 panels on grey, locations built around the action, prop and packaging sheets; Soul Cinema base then Seedream 5.0 Pro corrections, saved as char_x, loc_x) -> higgsfield-timed-prompts writes one timed Seedance 2.5 prompt per scene (cast block verbatim, LOOK line, continuous shot windows, fixed dialogue timestamps, CONTINUITY recap) -> proof one scene, fix assets not prompt -> top-down blocking diagram if seats or counts fail -> packshot scene (product readable first, one rack focus to the payoff, voice-over from frame 1) -> cut best takes. Settings seen: soul_cinematic 16:9 1080p, seedream_v5_pro 16:9 2k, seedance_2_5 16:9 1080p, durations 18, 19 and 4 s. QA: seat and place-setting counts, label legibility, face drift, one phone or prop. Compliance: unbranded props, fictional cast labelled AI. Conflicts with our rules are resolved in the realism file (official docs win).

## 13. Clip channel (long video to short edits for income; details: clipping-business.md)
Chain: rights check (own footage, written permission or official clipping program) -> pick 1 source, 1 reference edit, 1 music track -> Katana or edit-director first edit with plan and preview -> approve direction -> batch of 10 vertical edits, each a different moment and hook -> captions inside safe areas -> language version if asked -> QA (claims, AI label) -> deliver. TikTok is banned in India. Income figures are creator claims (U).

## 14. Single-camera multi-angle cut (creator blog 2026-09-16)
One wide static take with clean audio -> write the shot schedule in plain words -> Claude expands it into a timed Seedance 2.5 prompt (reference locks, hard cuts at stated times, output time t equals source time t) -> generate any off-footage subject separately and attach as an image. See signature-shots.md.
